# Bangladesh Vice City Multiplayer (VC:MP) Cloud Server & Web Admin

এই রিপোজিটরিটি ব্যবহার করে আপনি আপনার পিসিতে কোনো প্রেশার না দিয়ে সম্পূর্ণ বিনামূল্যে ২৪/৭ ক্লাউডে অথবা গিটহাবে আপনার ভাইস সিটি মাল্টিপ্লেয়ার সার্ভার চালাতে পারবেন।

---

## গিটহাবে আপলোড করার পদ্ধতি (How to Upload to GitHub)

### ধাপ ১: GitHub এ নতুন রিপোজিটরি তৈরি
1. আপনার ব্রাউজারে [GitHub.com](https://github.com) এ লগইন করুন।
2. উপরে ডানপাশে `+` চিহ্নে ক্লিক করে **"New repository"** সিলেক্ট করুন।
3. রিপোজিটরির নাম দিন, যেমন: `vcmp-cloud-server`।
4. এটিকে **Public** অথবা **Private** রেখে **"Create repository"** বাটনে ক্লিক করুন।

### ধাপ ২: ফাইলগুলো গিটহাবে আপলোড
- **সহজ উপায় (ব্রাউজার থেকে):** 
  - রিপোজিটরি তৈরি করার পর পেজে **"uploading an existing file"** লিঙ্কে ক্লিক করুন।
  - এই ফোল্ডারের (`GitHub_VCMP_Server`) সব ফাইল ও ফোল্ডার ড্র্যাগ অ্যান্ড ড্রপ (drag & drop) করে টেনে ছেড়ে দিন।
  - নিচে **"Commit changes"** এ ক্লিক করলেই ফাইলগুলো আপলোড হয়ে যাবে।

## সার্ভার ক্লাউডে ২৪/৭ ফ্রি চালানোর পদ্ধতি

### উপায় ১: GitHub Codespaces (১ ক্লিকে ক্লাউডে রান)
1. আপনার গিটহাব রিপোজিটরিতে যান।
2. সবুজ রঙের **`Code`** বাটনে ক্লিক করুন।
3. **`Codespaces`** ট্যাবে গিয়ে **"Create codespace on main"** এ ক্লিক করুন।
4. ক্লাউড ব্রাউজারেই লিনাক্স টার্মিনাল ওপেন হবে।
5. টার্মিনালে শুধু লিখুন:
   ```bash
   wine64 server64.exe
   ```
   সার্ভার অনলাইনে চালু হয়ে যাবে! প্রতি মাসে ৬০ ঘণ্টা সম্পূর্ণ ফ্রিতে ব্যবহার করা যায়।

### উপায় ২: ওরাকল ক্লাউড (Oracle Cloud Always Free VPS - আজীবন ফ্রি ২৪/৭)
- Oracle Cloud-এ ২৪ জিবি র‍্যাম ও ৪ সিপিইউ-এর সম্পূর্ণ ফ্রি আজীবন ক্লাউড সার্ভার পাওয়া যায়।
- সেখানে এই রিপোজিটরি ক্লোন করে বা ডকার দিয়ে সহজেই রান করা যায়:
  ```bash
  docker build -t vcmp-server .
  docker run -d -p 8192:8192/udp -p 8080:8080/tcp vcmp-server
  ```

## ব্রাউজার ওয়েব এডমিন প্যানেল (Web Admin Dashboard)
- এই রিপোজিটরির `docs/index.html` ফাইলে সম্পূর্ণ তৈরি করা আছে রেসপনসিভ ওয়েব এডমিন প্যানেল।
- গিটহাব রিপোজিটরির **Settings -> Pages** এ গিয়ে Source হিসেবে `Branch: main, /docs` সিলেক্ট করলে আপনার এডমিন প্যানেলটি ফ্রি ওয়েবসাইটে রূপান্তরিত হবে: `https://<your-username>.github.io/vcmp-cloud-server/`
- ব্রাউজার থেকেই আবহাওয়া, প্লেয়ার, আরকন কমান্ড ও ফায়ারবেস ক্লাউড ডেটাবেস নিয়ন্ত্রণ করতে পারবেন।
